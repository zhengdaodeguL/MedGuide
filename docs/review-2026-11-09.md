# MedGuide 修缮与验收记录

日期：2026 年 11 月 9 日。范围：工作流编排迁移、界面重构、回归 review。验收时修改尚未提交、推送或部署；后续提交状态以 Git 历史为准。

## 本轮交付

- 编排依赖迁移至 LangGraph 1.2.20、LangChain Core 1.7.6，并在项目虚拟环境中安装验证。依赖上界限制在 2.0 之前；OpenAI SDK 保持现有主版本。
- 工作流版本为 `2026.11`，风险筛查后按普通资料检索、结构化查询或直接整理就医指引分流。高风险结构化请求只经过查询门禁，返回阻断结果，不执行 SQL。
- 保留九节点事件契约，跳过节点明确标为 `skipped`；公开状态携带实际路径、跳过节点及编排版本，支持最终响应和请求恢复。
- 界面改为纸白、深墨色与单一蓝绿色的三栏健康信息工作台。移除当前页面的风景背景与装饰性动效，重做登录、注册、会话、资料及移动抽屉的视觉层级。
- 参考 21st.dev 的公开界面作为视觉研究，沿用 React、原生 CSS 与现有图标库，没有引入额外组件框架。

## Review 发现及修复

| 问题 | 修复 | 验证方式 |
| --- | --- | --- |
| 条件跳过节点后，上轮查询结果或引用可能残留 | 每轮入口清空查询、引用及检索改写状态 | 两种 runner 的 SQL / RAG 多轮切换回归 |
| 请求回放的事件与当前轮编排元数据可能不一致 | 持久化并恢复对应轮的编排元数据 | 请求历史回放回归 |
| 取消请求需要明确的逐节点停止边界 | 取消感知调用采用可检查取消标记的执行路径 | 取消回归 |
| 重复 SSE 节点事件可能错误推进进度 | 按节点去重，按所需节点集合计算四阶段状态 | 前端节点重复及条件跳过测试 |
| JSON 回放与断流恢复可能丢失处理进度 | 按响应 Content-Type 解析，最终状态恢复节点信息 | 前端测试与浏览器夹具交互 |
| 离线环境缺少 Redis 包时，轻量 pipeline 测试替身无法导入异常类型 | 增加仅在缺包时使用的兼容异常类型 | 后端全量回归 |
| 注册页确认密码锁图标落入正常文档流 | 图标定位到密码控件内部 | 桌面注册页截图及 DOM 边界检查 |

修复后的最终只读 review 未发现新的可复现阻断问题；这不等同于生产环境或临床有效性认证。
